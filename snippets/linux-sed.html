Linux sed Command Examples

sed (stream editor) is a powerful Unix utility for parsing and transforming text. It is essential for automating text substitutions, deletions, and edits in files and pipelines without opening an editor.

Linux sed CLI Text Processing
Basic Substitution
Replace first occurrence on each line 
sed 's/old/new/' file.txt
Substitutes the first occurrence of "old" with "new" on every line. The output is printed to stdout; the original file is not modified. Pipe or redirect to save changes.
Replace all occurrences (global flag) 
sed 's/old/new/g' file.txt
The g flag replaces every occurrence of "old" on each line, not just the first. This is one of the most commonly used sed patterns for bulk text replacement.
Edit file in-place 
sed -i 's/old/new/g' file.txt
The -i flag edits the file directly without needing to redirect output. Use with caution as the original content is overwritten. Always test the substitution without -i first.
Edit in-place with backup 
sed -i.bak 's/old/new/g' file.txt
Appending a suffix to -i (e.g., .bak) creates a backup of the original file before editing. The backup is saved as file.txt.bak, giving you a safety net.
Line Operations
Delete a specific line by number 
sed '5d' file.txt
Deletes line number 5 from the output. Line numbers are 1-based. You can also use a range like '5,10d' to delete lines 5 through 10.
Delete lines matching a pattern 
sed '/^#/d' file.txt
Deletes all lines that match the given regex pattern. This example removes comment lines starting with #. Useful for stripping comments from config files.
Delete blank lines 
sed '/^$/d' file.txt
The pattern ^$ matches empty lines (start of line immediately followed by end of line). This is a quick way to remove all blank lines from a file.
Print a specific line number 
sed -n '10p' file.txt
The -n flag suppresses default output, and p explicitly prints matching lines. Together they print only line 10. Without -n, the line would appear twice.
Print a range of lines 
sed -n '10,20p' file.txt
Prints lines 10 through 20 inclusive. A faster alternative to head | tail for extracting a specific section of a large file.
Advanced
Multiple substitution commands 
sed -e 's/foo/bar/g' -e 's/baz/qux/g' file.txt
The -e flag allows chaining multiple sed expressions in one command. Each expression is applied in sequence. An alternative is to use a semicolon: sed 's/foo/bar/g; s/baz/qux/g' file.txt.
Insert a new line after a matching line 
sed '/pattern/a\New line of text' file.txt
The a command appends text after each line matching the pattern. Use i instead of a to insert before the matching line. Useful for injecting config entries after a specific marker.

How to Use

  1. Test your sed expression without -i first to verify the output looks correct.
  2. Use -i.bak instead of -i when editing files in-place to keep a backup.
  3. Chain multiple operations with -e or semicolons to perform several edits in one pass.
  4. Combine with pipes: cat file.txt | sed 's/old/new/g' or grep pattern file | sed ....
  5. Use single quotes around the sed expression to avoid shell interpretation of special characters.

Frequently Asked Questions

What is the difference between sed -i and sed -i.bak?

Both edit the file in-place, but -i.bak saves a copy of the original with a .bak extension before making changes. Using a backup suffix is a safer practice especially when running sed on important configuration files.

Why does my sed command work differently on macOS vs Linux?

macOS uses BSD sed, which has slightly different syntax than GNU sed on Linux. The most common difference is with -i: on macOS you must provide a suffix (e.g., -i ''), while GNU sed accepts -i alone. Install GNU sed via Homebrew (brew install gnu-sed) for consistent behavior.

Can sed handle multi-line patterns?

Yes, but it requires using the N command to read the next line into the pattern space. For complex multi-line transformations, awk or perl -0777 -pe are often more readable alternatives.
