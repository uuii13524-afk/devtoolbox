Linux awk Command Examples

awk is a versatile text-processing language built into every Unix/Linux system. It excels at column-based data extraction, filtering, and generating reports from structured text files.

Linux awk CLI Text Processing
Field Extraction
Print the first field of each line 
awk '{print $1}' file.txt
awk splits each line into fields by whitespace. $1 refers to the first field, $2 to the second, and so on. This is useful for extracting usernames, IP addresses, or any first column of structured output.
Print multiple fields 
awk '{print $1, $3}' file.txt
Prints the first and third fields separated by a space. Using a comma between fields in the print statement inserts the output field separator (OFS), which defaults to a space.
Use a custom field delimiter 
awk -F',' '{print $2}' file.csv
The -F flag sets the field separator. Here it is set to a comma for processing CSV files. You can also use any regex as the delimiter, e.g., -F'[,;]' to split on comma or semicolon.
Print the last field 
awk '{print $NF}' file.txt
NF is a built-in variable holding the number of fields on the current line, so $NF always refers to the last field regardless of how many fields exist.
Filtering
Print lines matching a pattern 
awk '/ERROR/ {print}' file.txt
Pattern matching in awk works similarly to grep. Only lines where the regex matches are passed to the action block. Omitting the action block also works: awk '/ERROR/' file.txt.
Print line numbers with each line 
awk '{print NR, $0}' file.txt
NR is the current record (line) number. $0 is the entire line. This is a quick way to add line numbers to any file or command output.
Filter lines by field value 
awk '$3 > 100 {print $1, $3}' file.txt
Prints columns 1 and 3 only for lines where the third field is greater than 100. awk supports standard comparison operators (>, <, ==, !=) for numeric and string comparisons.
Computation
Sum a numeric column 
awk '{sum += $1} END {print sum}' file.txt
Accumulates the value of the first field across all lines and prints the total in the END block. The END block runs once after all input has been processed, making it ideal for aggregate calculations.
Count lines matching a pattern 
awk '/pattern/ {count++} END {print count}' file.txt
Increments a counter for every line matching the pattern, then prints the total at the end. This is similar to grep -c but with the flexibility to add more complex conditions.
Calculate the average of a column 
awk '{sum += $1; count++} END {print sum/count}' file.txt
Tracks both the running sum and the line count, then divides at the end to produce the average. Add a check like count > 0 ? sum/count : 0 to avoid division by zero on empty files.

How to Use

  1. Run awk '{print $1}' file.txt to inspect the first column and verify your field splitting.
  2. Use -F to set the correct delimiter for CSV, TSV, or other structured files.
  3. Add pattern filters before the action block to process only relevant lines.
  4. Use BEGIN and END blocks for setup and teardown (e.g., printing headers or totals).
  5. Test with a small sample file before running on large inputs.

Frequently Asked Questions

What is the difference between awk and sed?

sed is a stream editor best suited for simple text substitutions and line deletions. awk is a full programming language with variables, loops, and arithmetic, making it better suited for column-based data extraction, filtering, and calculations. For simple replacements use sed; for structured data processing use awk.

How do I process a CSV with quoted fields containing commas?

Basic awk with -F',' does not handle quoted CSV fields correctly. For proper CSV parsing, use a tool like csvkit, python csv module, or GNU awk's FPAT feature: awk 'BEGIN{FPAT="([^,]+)|(\"[^\"]+\")"}'.

Can awk process multiple files at once?

Yes, just pass multiple filenames: awk '{print FILENAME, $0}' file1.txt file2.txt. The built-in variable FILENAME contains the name of the current file being processed, and FNR resets the line counter for each new file (unlike NR which keeps counting).
