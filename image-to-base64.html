How to Use

  1. Click the upload area or drag and drop any image file (PNG, JPEG, GIF, WebP, SVG, BMP, ICO) onto the drop zone.
  2. The tool instantly reads the image in your browser, shows a preview, and outputs the full Base64-encoded data URL.
  3. Use the tabs to switch between the full data URL, Base64 string only, a ready-to-paste HTML <img> tag, or a CSS background-image rule.
  4. Click Copy to copy the output to your clipboard, or Download .txt to save it as a text file.
  5. Use the metadata panel to check file size, MIME type, and image dimensions before embedding.

About This Tool

Base64 encoding converts binary image data into ASCII text, allowing images to be embedded directly into HTML, CSS, JSON, or XML without needing a separate file request. This is useful for small icons and logos in CSS, email templates that block external images, single-file HTML documents, or data URIs in SVG. The format of a data URL is data:[MIME type];base64,[encoded data]. For example, a small PNG becomes data:image/png;base64,iVBORw0KGgo.... Note that Base64 encoding increases file size by approximately 33% compared to the binary original, so embedding large images via Base64 can significantly increase page weight. This tool runs entirely in your browser using the FileReader API — your image data is never uploaded to any server.

Frequently Asked Questions

Why is the Base64 output larger than the original image?

Base64 encodes every 3 bytes of binary data as 4 ASCII characters, resulting in a size increase of approximately 33%. A 100 KB PNG image will produce roughly 133 KB of Base64 text. For this reason, Base64 embedding is best suited to small images like icons; for larger images, serving them as regular files is more efficient.

Is my image uploaded to a server?

No. This tool uses the browser's built-in FileReader API to read your file locally. Your image data never leaves your device and is never sent to any server. The encoding happens entirely in JavaScript within your browser tab.

Which image formats are supported?

Any image format your browser supports can be encoded: PNG, JPEG/JPG, GIF, WebP, SVG, BMP, and ICO are all supported. The MIME type is detected automatically from the file and included in the data URL (e.g., data:image/png;base64,...). SVG files are treated as image/svg+xml.
